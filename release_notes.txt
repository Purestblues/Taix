# v{version} 更新日志

> 本版本基于上游 [NLick47/Taix](https://github.com/NLick47/Taix) v1.3.4 的个人 fork，接在 `fork.7`（视觉体系 v1 + 动效 v2）之后。
> **这一版动了分类页的卡片结构，其余页面的数据结构与统计口径与 fork.7 完全一致。**

## 主要变化

- **分类页：卡片瘦身 + 显示时长**
  - 原来每张卡是 150×150 的方块，只有「图标 + 名称 + ×应用数」，一屏只放得下 6 个，
    下面大片空白；分类一多就得滚很久，而最有用的「这个分类今天花了多久」反而不在卡上
  - 现在每张卡 200×92：图标 + 名称 + 今日时长在一行，应用数降为下面一行小字，
    底部是一条占比条 + 百分比
  - 一屏从 5 列 × 2 行 ≈ 6 个，变成 6 列 × 约 7 行 ≈ 40 个
  - 排序：有数据的按时长从多到少排，今天没用过的收在后面按名称排（不再挤占第一屏）
  - 「目录匹配 / 通配符匹配」原来是一块盖在图上的药丸，现在是图标右上角一个小圆点（悬停看说明）
  - 时长的口径是**今天**，与应用数一样不区分周期；应用与网站两个视图各自按自己的分类体系统计

- **第二强调色落地**：新增 `#FF4081` 作为「瞬时交互 / 差额项」的专用色，
  目前用在概览页「比昨日」对比柱（同一时段的上一周期）——原来那是半透明灰，在浅色下几乎看不见

- **组件里的散装颜色收进主题 token**：删除按钮的红色、状态点的灰、macOS 通知的成功 / 失败色、
  网站徽章的蓝、遮罩的黑、色板选中环、窗口与分类页阴影，共 25 处。换主题时这些会跟着一起变

## 修复

- **深色模式下「意外错误」弹窗整块发白**：对话框内容区写死了浅灰底 `#f3f3f3`，深色下非常刺眼。
  改为走弹窗背景色 + 发丝边 + 统一阴影
- **折叠面板只有箭头能点，点标题没反应**：`Expander` 模板里只有右侧箭头绑了命令，
  而且那个命令从来没人赋值，所以点哪儿都不会动。现在整条头部都是点击热区，箭头会跟着展开状态转向
  - 说明：这个控件目前只有设置页的「多例面板」在用，而当前两个设置面板传的都是单个对象，
    所以你在设置页**看不到变化**。修的是控件本身，等这个面板真正启用时才生效
- **列表卡片上的杂色**：分类编辑框的关闭按钮原来是写死的浅灰（浅色主题下几乎看不见），改为跟随主题

## 升级注意事项

1. 本版不带数据结构变更，直接覆盖安装即可，历史数据不需要迁移。
2. 主题色与明暗模式仍存在服务端配置里，升级后保持你原来的选择。
3. 分类页的「今日时长」需要客户端能连上本地 `shijian-server`；连不上时卡片显示「—」，不影响其它页面。

## 已知问题

- macOS 产物仍然只验证过「能构建 + 打包成功」，没有 Apple Silicon 机器实机跑过。
- 分类页暂时只有「卡片」一种视图，还没有「紧凑 / 卡片」切换与手动排序菜单（已排进下一版）。
- 分类卡片宽度是固定 200px，不随窗口宽度变列数；窗口很宽时右侧会留白。
- 环形时钟中心时长（会话口径）与指标卡 / 柱图（小时桶口径）仍可能差几分钟，属历史口径差异，未强行统一。

## 工程侧

- 自动化测试 79 → **90** 例
  - 新增 `CategoryCardStatsTests` 8 例：不同分类行相加、总时长为 0 不除零、0 时长不进前段、
    卡片文案（无数据时显示「—」）
  - 新增 `ExpanderHeaderTests` 3 例：点标题真能展开 / 收起、箭头跟随状态、
    以及「新增的颜色 token 必须三套主题（暗 / 亮 / 蔚蓝）都存在」——漏一套会静默回落到暗色值，
    「浅色模式卡片全黑」就是这么来的
- 新增 `Librarys/CategoryCardStats`（分类时长求和 / 占比写回 / 排序）与
  `Models/Category/CategoryCardModel`（应用分类与网站分类共用的卡片统计基类）
- 分类页原来为每个分类串行请求一次应用数，现在改成并发；分类时长只需额外一次请求就能拿全
