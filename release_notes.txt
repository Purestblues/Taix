# v{version} 更新日志

> 本版本基于上游 [NLick47/Taix](https://github.com/NLick47/Taix) v1.3.4，是个人修改版（fork），改动集中在客户端。

## 主要变化

- **概览页重做**：新增总览卡片（总使用时长 / 应用量 / 站点 / 网页，带比昨日、比上周升降）、使用时段堆叠柱图、分类占比环形图，图表区可在「应用 / 网站」之间切换
- **图表配色统一**：系统分类「未分类」的颜色原本是 `#e4e3df`（几乎等于背景色），导致图表看上去像没数据。现改为跟随主题色，其余过浅的分类色自动压暗，统计页同样生效
- **交互与动效**：双击标题栏最大化/还原、窗口最外缘可拖拽缩放、页面进场淡入、总览卡错峰进场、榜单进度条生长动画、总览数字滚动

## 优化与修复

- 修复首页应用/网站图标全部回退默认图标：客户端只在 `<exe>\AppIcons` 查找，而服务端实际写在 `<exe>\Data\AppIcons`
- 修复最大化后还原不回原尺寸；退出时不再把满屏中间尺寸当成正常尺寸保存
- 修复窗口最外侧 16 像素是缩放死区（`WM_NCHITTEST` 返回 `HTCLIENT`，只有在卡片边缘往内 8 像素的窄带里才能拖动）
- 新增 `script/dev-run.ps1`：本地调试时为开发目录补齐图标并启动客户端

## 已知问题

- 深色主题下图表配色的阈值是按浅色背景校准的，深色下可能偏暗，尚未单独处理

## 下载与安装

本次发布提供以下产物，按需选择

| 产物 | 文件名 | 适用场景 |
| --- | --- | --- |
| Windows 安装器 | `Taix-{version}-Setup.exe` | 推荐普通用户使用 |
| Windows 绿色版 | `Taix-{version}-win-x64.zip` | 便携使用，需手动执行脚本注册开机自启（任务计划）服务 |
| macOS | `Taix-{version}-macos-arm64.dmg` | Apple Silicon 设备，macOS 12.0+ |

### Windows 安装器（推荐）

1. 下载 `Taix-{version}-Setup.exe`
2. 双击运行，按引导完成安装
3. 安装器会自动注册服务并启动，无需手动操作

> 💡 **从绿色版切换到安装器**：若想从绿色版切换到安装器，只需指定安装器的安装目录为绿色版 exe 文件所在的文件夹，安装器会自动完成服务停止和文件替换

### Windows 绿色版

1. 下载并解压 `Taix-{version}-win-x64.zip` 到任意目录（建议非系统盘）
2. 以**管理员身份**打开 PowerShell，进入解压目录
3. 运行 `install.ps1` 完成服务注册（脚本成功后会自动启动相关服务）
4. 卸载时同样以管理员身份运行 `uninstall.ps1`

> ⚠️ **重要**：`install.ps1` 会创建任务计划并指向当前解压目录，因此绿色版**安装后请勿移动或重命名该目录**，否则任务计划指向的路径失效将导致开机自启失败。若必须迁移位置，将整个目录移动到新位置后，直接在新目录重新运行 `install.ps1` 即可（脚本会强制覆盖原任务计划并刷新指向路径）

> 绿色版升级：若从 1.2.0 及之后版本升级，可解压后直接替换 exe；若更换了安装目录，在新目录运行 `install.ps1` 即可覆盖注册，请保留原图标目录与数据目录

### macOS

DMG 内含 `Taix.app`（客户端）和 `TaixTools/`（后台服务 + 安装脚本），两者都需要部署

1. **清除隔离标记**：
   ```bash
   xattr -dr com.apple.quarantine ~/Downloads/Taix-{version}-macos-arm64.dmg
   ```
2. 将 `Taix.app` 和 `TaixTools` 一起拖入 `Applications`
3. 终端运行 `/Applications/TaixTools/install-launchagent.sh` 注册后台服务
4. 启动 `Taix.app`

跳过第 1 步的补救：启动被拦截时右键 Taix.app → 「打开」→ 弹窗中确认，或到「系统设置 → 隐私与安全性」点击「仍要打开」。每次重新下载新版 DMG 都会重新带上隔离标记，更新时需再次执行第 1 步。

卸载运行 `/Applications/TaixTools/uninstall.sh`


## 注意事项

**1. 从上游版本升级**

本版数据目录、配置格式与上游 v1.3.4 完全一致，可以直接覆盖安装，原有统计数据和分类不会丢。但**建议先备份 `<安装目录>\Data\data.db`**。

**2. 启动时间说明**

> ⚠️ **重要**：1.2.6 版本已针对冷启动优化，自测冷启动在 0.5 秒左右。若启动时间明显偏长，可能是腾讯电脑管家等安全类软件扫描拦截所致，可将其加入对应软件的信任白名单

**3. Windows 绿色版升级可删除旧动态库**

> 新版已改为全静态链接，客户端只依赖一个 exe。若你是绿色版、直接替换 exe 升级，旧目录中遗留的 `libSkiaSharp.dll`、`libHarfBuzzSharp.dll`、`av_libglesv2.dll` 三个文件已不再使用，可手动删除
