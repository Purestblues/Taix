# v{version} 更新日志

> 本版本基于上游 [NLick47/Taix](https://github.com/NLick47/Taix) v1.3.4，是个人修改版（fork）。
> **这一版只做一件事：改名。** Taix → 时见 / ShiJian，代码标识、安装标识、数据目录一次性换掉，
> 历史数据自动迁移，功能与上一版（fork.5）完全一致。

## 主要变化

- **改名：Taix → 时见 / ShiJian**
  - 中文界面显示「时见」，英文界面显示 ShiJian；程序、目录、crate、命名空间统一为 `ShiJian` / `shijian-*`
  - 安装目录：`…\Taix` → `…\ShiJian`（Setup 里仍可自选）
  - macOS 数据目录：`~/Library/Application Support/Taix` → `…/ShiJian`
  - 计划任务 / LaunchAgent：`TaixShell` / `com.taix.shell` → `ShiJianShell` / `com.shijian.shell`
  - 环境变量：`TAIX_SERVER` / `TAIX_LOG_DIR` → `SHIJIAN_SERVER` / `SHIJIAN_LOG_DIR`
  - 端口不变（HTTP 37091 / 扩展 WS 8908），插件通信不受影响
  - **仓库也改名**：`Purestblues/Taix` → [Purestblues/shijian](https://github.com/Purestblues/shijian)（旧地址会 301 重定向）

- **历史数据自动迁移，不会丢**
  - Windows：Setup 在装之前先停掉旧进程、摘掉旧自启动项，再把旧安装目录的 `Data/` 合并进新目录
    （只补不覆盖，目标里已有的文件不动）
  - macOS：server 启动时把 `Application Support/Taix`、`Library/Logs/Taix`、`Library/Caches/Taix`、
    `/Applications/TaixTools` 里缺失的条目补进新名字下，并停掉旧进程与旧 LaunchAgent
  - 旧的安装目录 / 数据目录**不会被删除**，确认新版本正常后可以自己清理

- **应用内链接指向自己的仓库**：顺手修掉一个隐患——原来的「检查更新」指向上游 releases，
  点下去会装回上游旧版本；现在指向 `Purestblues/shijian` 的 releases。

## 升级注意事项

1. **浏览器扩展要重新加载**：扩展目录名变了（`taix-browser-extension` → `shijian-browser-extension`），
   重新「加载已解压的扩展程序」即可。未打包扩展的 ID 会随路径变化，
   如果你在服务端配过 Origin 白名单，需要把新的扩展来源补进去。
2. **自己写的脚本如果用了 `TAIX_*` 环境变量**，要改成 `SHIJIAN_*`。
3. 装完如果看到旧版本的自启动项还在（任务计划里带 `Taix` 的条目），删掉即可；
   安装器正常情况下会自己清。
4. 覆盖安装前建议先退出正在运行的旧版本（托盘 → 退出），
   否则安装器会强停进程——数据库本身是安全的，只是可能丢失最后几秒的记录。

## 已知问题

- 目录里的旧安装残留（`…\Taix`）需要手动删，本项目不会替你删文件。
