# v{version} 更新日志

> 本版本基于上游 [NLick47/Taix](https://github.com/NLick47/Taix) v1.3.4 的个人 fork，接在 `fork.6`（改名）之后。
> **这一版只动外观与动效，功能与数据口径与 fork.6 完全一致。**
> 视觉与动效的目标来自开源项目 [Super Productivity](https://github.com/johannesjo/super-productivity)。

## 主要变化

- **视觉体系：卡片换成「8px 圆角 + 1px 发丝边 + 零阴影」**
  - 原来各页卡片圆角 10/12/14/16 混用、多数没有边框、靠深灰色块分层次；现在统一为一套语汇
  - 共整理 8 个页面 29 个卡片容器（统计 / 分类 / 分类汇总 / 详细 / 应用详情 / 网站详情 / 设置 / 搜索结果）
  - 阴影只留给真正浮起来的层（弹窗、浮层），卡片静置零阴影

- **明暗两套色板重做**
  - 暗色：页面 `#131314`、卡片 `#242424`、抬升 `#333`，去掉原来的偏蓝色调
  - 亮色：页面 `#F8F8F7`、卡片 `#FFF`——亮色刻意不用明度分层，层级靠发丝线
  - 文字四档按对比度重排（正文不再用纯黑，次要文字保证 WCAG AA）

- **主题色默认改为紫**
  - 暗色用亮一档 `#C08AC9`，亮色用 `#A05DB1`；图表兜底色、焦点环、无分类时的图表色同步
  - ⚠️ 主题色存在服务端配置里，**升级后仍是你原来的颜色**（比如蓝色）。想用新紫色请到 设置 → 主题颜色 重新选

- **榜单行改成扁平行**：50px 圆角色块 → 26px 图标、名称 13px、进度条 8px → 3px、行底 1px 发丝线

- **留白与氛围**：页面边距 20 → 24、滚动页底部留 64px 呼吸；内容区加两层极淡径向光晕（明暗不同参数）

- **动效体系 v2（按参考项目的标尺重做）**
  - 时长只有四档：90 / 150 / 225 / 375ms；曲线只有三条：standard / enter / leave
  - 换页：旧页不再硬切，新页 180ms 淡入（延迟 45ms）+ 8px 上移，总计 225ms
  - 展开 / 收起（概览「自定义」范围面板、设置页规则列表）走高度动画，不再是硬跳
  - 界面里散落的 12 个文件过渡时长全部归一到上面四档

## 修复

- **换页动效其实从未生效**：Avalonia 12 移除了 `Animation.Animators`，关键帧里带 `RenderTransform` 会让整个动画在开头就抛异常并被吞掉，页面直接就位。现在位移改为逐帧插值，并且动画失败会写日志。
- **浅色模式卡片全黑**：新增的颜色 token 只加进了暗色字典，浅色模式回落到深色值。现在两套字典都补齐。
- **榜单进度条不显示 / 快速滚动后消失**：宽度靠代码手算，虚拟化复用行时容器尺寸不再变化，宽度永久停在 0。改为绘制时按实际宽度现算。
- **概览卡片 hover 上浮无效**：与第一条同源（RenderTransform 不可动画），现在改为只变边框色。
- **设置页规则列表展开 / 收起无动画**：`Expander` 的 `OnExpand()` 原本是空方法。

## 升级注意事项

1. 本版不带数据结构变更，直接覆盖安装即可，历史数据不需要迁移。
2. 主题色不会自动更新（见上文），语言、动效开关等设置保持不变。
3. 如果你之前手动改过 `app.config.cache.json` 里的颜色值，升级后会被服务端配置覆盖，属正常行为。

## 已知问题

- macOS 产物仍然只验证过「能构建 + 打包成功」，没有 Apple Silicon 机器实机跑过。
- 设置页「忽略应用 / 忽略 URL」的折叠头没有展开箭头，点标题也没反应（只有右侧 `...` 菜单可用）。
- 分类页信息密度偏低（150×150 方块卡，一屏 3–4 个），已排进下一版。
- 环形时钟中心时长（会话口径）与指标卡/柱图（小时桶口径）仍可能差几分钟，属历史口径差异，未强行统一。
