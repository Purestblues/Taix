# v{version} 更新日志

> 接在 `fork.10.6`（`/api/entity/summary` + 统计与详细页切实体源）之后。这一版带来了**分类页「分类 / 应用」双视图重做**、**子母程序自定义合并组**（支持应用与网站跨界混编），并将全站各页面及右键菜单全量对齐至统一实体模型。

## 主要变化

- **分类页重做（N5）**
  - **分类 / 应用双视图切换**：新增「分类视图」与「应用视图」切换；应用视图下平铺展示所有应用与网站实体，并支持直接点击标签胶囊快速更换分类与打标签
  - **空分类智能折叠**：分类视图下自动折叠无统计数据的空分类，精简视觉空间，支持一键展开/收起
  - **多维过滤与排序**：支持按「全部 / 未分类 / 已分类」过滤，以及按「今日时长 / 总时长 / 名称」排序，并集成实体实时关键词搜索

- **子母程序自定义合并组（N6 进阶）**
  - **跨界混编合并**：服务端新增 `/api/entity/merge-groups/create` 与 `/api/entity/merge-groups/update` 接口，支持手动创建合并组、重命名、指定主实体（Primary Ref）与增删成员，支持应用与网站混合合并进同一组，且总时长严格守恒
  - **设置页合并组管理交互重整**：新增「新建合并组」弹窗、候选实体搜选器、主实体标识与 App / Site 实体类型徽章

- **全站实体模型收敛与右键菜单对齐**
  - 概览页、统计页、详细页彻底下线旧版独立的「应用 / 网站」双轨切换器，统一采用实体数据源与互斥口径
  - 右键上下文菜单全面适配 `EntityModel`，右键点击实体可自动识别应用或网站并唤起对应的管理菜单
  - 提醒插件（reminder UI）与 WebUI 同步适配合并组折叠（foldAppOptions）

- **测试集与文档更新**
  - 新增 `CategoryEntityViewHelperTests`、`SearchServiceTests`、`manual_mixed_group_create_update_and_conservation` 等测试，.NET 测试（149 项）、Rust 单元测试（39 项）及插件测试（21 项）全数通过
  - 规划文档新增登记第二批产品需求（N8–N15）

## 升级注意事项

1. 服务端新增了 `/api/entity/merge-groups/create` 与 `/update` 接口，**建议同时升级客户端与服务端**。
2. 本版无破坏性数据库迁移，从 `fork.10` / `fork.10.5` / `fork.10.6` 直接覆盖安装即可。
3. 浏览器扩展沿用 `2.0.2`，无需重装。
